字庫來源與授權

每日勤練字隨附字型及社群筆順，可離線產生與列印練習紙。台灣教育部原圖是選用資料，預設不隨專案或 Docker 映像分發；使用者可按 README 說明自行下載並安裝。應用程式不儲存練習內容；只有點擊「台灣教育部動畫」或「香港教育局參考筆順」時，才把所選的單字傳送至來源網站。

預設筆順：AnimCJK 繁體（台灣）

預設使用 AnimCJK 的 graphicsZhHant，內建 1,013 字。選擇「筆順字庫字形」時，各練習方式均可在缺字時使用中國大陸 Hanzi Writer Data 後備，可取消勾選。已有的 AnimCJK 字仍優先用 AnimCJK；後備字會在預覽及印頁以 † 標明。點「AnimCJK 筆順」可預覽逐筆示範與描紅；筆畫資料隨網站附上，可離線使用。資料採 Arphic Public License。社群資料未經逐字核對為香港筆順。

台灣教育部原版筆順・6,063 字

來源：中華民國教育部《國字標準字體筆順學習網》。如自行安裝，原圖模式會使用官方教學資源 ZIP 中的完整「全筆順提示」PNG，保留原圖位元組、色彩、留白及長寬比例，旁邊另排練習格。印頁附署名及授權網址。原圖解析度有限，建議直向列印。

教育部版權說明明列筆順動畫及全筆順提示採用 CC BY-NC-ND 3.0 TW：姓名標示、非商業性、禁止改作，並允許非商業 iframe 引用。本程式將完整原圖與練習格分開排列；把這種排法視為授權所允許的彙編，是本專案的解讀，並非教育部對本專案的個別認可。原圖不能因程式碼開源而改標為其他授權。

安裝資料後，重新啟動網站即可選用「台灣教育部・原版筆順＋練習格」。缺字會保留練習格並標示「未收錄」，不會改用其他地區筆順或替換異體字。例如收錄「裡」但未收錄「裏」。教育部線上動畫無需額外安裝這份資料，但需連線；已安裝的原圖可離線列印。請在專案 README 查看下載與安裝步驟；詳細來源與檔案雜湊見教育部資料聲明。

香港教育局參考筆順

提供《香港小學學習字詞表》的逐字查詢，使用網站原本的表單開啟官方頁，沒有打包或重新託管其筆順素材。教育局的使用要則說明筆順屬參考性質，並非唯一、硬性的標準。

可調色的社群筆順資料

  • 中國大陸：Hanzi Writer Data 2.0.1，9,574 字，源自 Make Me a Hanzi。繁體字亦依此字庫的中國大陸筆順。
  • 台灣：AnimCJK 的 graphicsZhHant，1,013 字，版本 ec5e17cca76c87587790bcbce5ea0b4d4fb753d6。
  • 香港：未內建可調色筆順路徑字庫；可使用上述教育局網站查詢。

選用「筆順字庫字形」時，AnimCJK 只有缺字才套用中國大陸後備，並標明來源；例如「為甚麼」的「為」「麼」維持 AnimCJK，「甚」使用九筆 Hanzi Writer Data。後備字的字形或筆順可能與台灣標準不同。兩庫均缺字時只顯示一般範字。這些是社群整理的資料，並非地區教育部門認證的完整字庫；覆蓋範圍與參考網站不同。

內建字體

預設字體下，輸入欄沿用網站正文及設定標題的字體；字帖各模式逐字使用相同的筆順字庫字形，因此多字整行與筆順模式的同一字形一致。AnimCJK 已收錄字使用其原筆順路徑；後備字的範字、逐筆格及描紅全程使用 Hanzi Writer Data 路徑。不同來源的字形風格仍可能有別，印頁會標明後備字。兩個字庫都缺字時，範字使用內建的 霞鶩文楷 TC Regular。文楷採 SIL Open Font License 1.1，不保證符合台灣或香港教育字形標準。

選擇系統黑體或其他已安裝字體時，輸入欄、範字與描紅改用該字體，逐筆示範保留實際選用字庫的筆畫路徑。龐中華、田英章及自訂字體須安裝於列印的電腦；未安裝時以文楷替代。這些字體不隨專案分發。
