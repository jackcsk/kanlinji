Modification notice, 2026-09-22, kanlinji contributors:
Converted the bundled Taiwan stroke paths into an OpenType CFF font, retaining
their Y-up coordinates and 1024-unit em. Independent stroke contours are
oriented consistently so overlaps remain filled. Quadratic curves become
equivalent cubic curves at CFF coordinate precision. No missing glyphs were
added. This font is separate from the OFL-licensed LXGW font; a font stack
may use LXGW as a fallback for characters absent from AnimCJK. The current
input field uses the website's main UI font; printed stroke cells use the
selected stroke dataset's paths where available.
scripts/build-anim-font.py rebuilds this freely available derivative from the
pinned data/tw.json.gz, using fonttools 4.60.1 as a build-only dependency.
The runtime and Docker image do not require Python or fonttools.
